# Survival Analysis of Breast Cancer Data from Christie Hospital

R code used for the analyses in my MSc Statistics dissertation at the University of Manchester.

## Files

- `chapter1_preliminary_survival_analysis.R` — Chapter 1: preliminary analysis using `stime`, `cens`, and `age`.
- `chapter2_exploratory_analysis.R` — Chapter 2: exploratory analysis using the full data set.
- `chapter3_multivariable_cox_analysis.R` — Chapter 3: multivariable Cox modelling and diagnostics using the full data set.

## Data

The clinical data are not included in this repository.
